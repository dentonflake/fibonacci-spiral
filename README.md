# Fibonacci Spiral

# Overview

An interactive Fibonacci visualization built with JavaScript and P5.js. This application allows users to Explore different drawing styles which follow the Fibonacci sequence. The application uses recursion to draw the Fibonacci. 

My purpose for developing this software is to gain a better understanding of what Fibonacci is. I have recently been mesmerized by the Fibonacci and its golden ratio and how it works. For a while, I have been wanting to create it with code to gain an even deeper level of understanding of what is happening.

[Software Demo Video](http://youtube.link.goes.here)

# Development Environment

I used Vite to run a local development server and create production builds, and I used pnpm as my package manager to install tools such as P5.js. 

The software is written in JavaScript using ES modules, with HTML and CSS providing the page structure and styling. The P5 Duchess library handles canvas drawing, animation, keyboard input, and image export.
